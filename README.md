# MediCare – Smart Healthcare Appointment & Patient Support System

MediCare is a full-stack web application designed to streamline healthcare
appointment scheduling and provide patient support features. This project is
being built incrementally as a college project.

> **Note:** This project is currently in the initial setup phase. No features
> have been implemented yet.

---

## Planned Technology Stack

### Frontend

| Technology     | Purpose                                        |
| -------------- | ---------------------------------------------- |
| React.js       | Component-based UI library                     |
| Vite           | Fast development server and build tool         |
| JavaScript     | Programming language for the frontend          |
| HTML & CSS     | Page structure and styling                     |
| Axios          | HTTP client for calling backend REST APIs      |
| React Router   | Client-side page navigation                    |

### Backend

| Technology      | Purpose                                       |
| --------------- | --------------------------------------------- |
| Java            | Programming language for the backend           |
| Spring Boot     | Framework for building the REST API server     |
| Spring Web      | Module for creating REST controllers           |
| Spring Data JPA | Module for database access using Java objects  |
| Spring Security | Module for authentication and authorization    |
| JWT             | Token-based stateless authentication           |
| BCrypt          | Password hashing algorithm                     |

### Database

| Technology | Purpose                                  |
| ---------- | ---------------------------------------- |
| MySQL      | Relational database for persistent data  |

### Tools

| Tool    | Purpose                              |
| ------- | ------------------------------------ |
| Git     | Version control                      |
| Postman | API testing and debugging            |
